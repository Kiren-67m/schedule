# 📅 Course Schedule Manager

A comprehensive, ready-to-use course schedule management tool. Fully standalone, no server required - works directly in your browser!

## 🎯 Live Demo

👉 **[Try it now!](https://your-username.github.io/repo-name/)** (Replace with your GitHub Pages URL)

## ✨ Features

- 📊 **Dashboard** - One-stop overview of today's events and this week's schedule
- 📚 **Course Management** - Add, edit, and delete courses with meeting times
- 📅 **Schedule Views** - Table view and calendar view for different perspectives
- 📝 **Syllabus Parser** - Automatically extract deadlines, exams, and events from syllabus text
- 📥 **Calendar Export** - Export to ICS format for Google Calendar, Outlook, etc.
- 🌐 **Bilingual** - Supports Chinese and English interfaces
- 💾 **Local Storage** - All data stored locally in your browser

## 🚀 Quick Start

### For GitHub Pages (Online)

Simply visit the GitHub Pages URL above - no installation needed!

### For Local Use

1. **Download** this repository
2. **Open** `index.html` in your web browser
3. That's it! The app runs entirely in your browser

**No server, no installation, no dependencies!**
