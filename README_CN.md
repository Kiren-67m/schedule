# 📅 课程表管理系统 (Course Schedule Manager)

一个功能完整、开箱即用的课程表管理工具。完全独立运行，无需服务器，直接双击即可使用。

## 🎯 项目简介

这是一个专为学生设计的课程表管理系统，帮助您轻松管理课程安排、作业截止日期、考试时间以及个人活动。系统支持中英文双语界面，提供多种视图模式，并支持从 Syllabus（教学大纲）导入课程信息，一键导出到日历应用。

**技术栈：** Alpine.js + Tailwind CSS + 纯 JavaScript（无构建工具）

**数据存储：** 浏览器 localStorage（所有数据保存在本地）

**兼容性：** 现代浏览器（Chrome、Firefox、Safari、Edge）

## 🚀 快速开始

### 安装与运行

1. **下载文件**
   - 解压 `package` 文件夹
   - 找到 `standalone.html` 文件

2. **启动应用**
   - **方式一：** 双击 `standalone.html` 文件
   - **方式二：** 右键点击文件 → "打开方式" → 选择浏览器
   - **方式三：** 打开浏览器 → 文件 → 打开文件 → 选择 `standalone.html`

3. **首次使用**
   - 首次打开会自动显示加载界面
   - 加载完成后自动进入 Dashboard（仪表盘）视图
   - 建议先设置学期信息（Settings → Term Settings）

### 系统要求

- **操作系统：** Windows、macOS、Linux（任何支持浏览器的系统）
- **浏览器：** Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- **网络连接：** 首次加载需要网络（加载 CDN 资源），后续可以离线使用部分功能

## ✨ 核心功能

### 1. 📊 Dashboard（仪表盘）

Dashboard 是系统的首页，提供一站式概览。

**功能特点：**

- **今日重要事项 (Today's Important Events)**
  - 自动显示今天所有的重要事件（考试、作业截止日期等）
  - 用红色高亮提醒，避免遗漏

- **本周课表 (This Week Schedule)**
  - 显示本周所有课程安排
  - 包含课程名称、时间、地点、授课方式（在线/线下）
  - 自动根据当前日期筛选

- **近期重要事项 (Upcoming Events - Next 14 Days)**
  - 显示未来 14 天内的所有重要事件
  - 包含考试、作业截止日期、个人活动、学术日历事件
  - 按时间顺序排列，重要事件优先显示

### 2. 📚 课程管理 (Course Management)

#### 添加课程 (Add Course)

1. 点击导航栏的 **"+ Add Course"** 按钮
2. 填写课程信息：
   - **Course Name（课程名称）**：例如 "ITC 535"
   - **Course Number（课程编号）**：例如 "001"
   - **Section（班级编号）**：例如 "001"
   - **Instructor（授课教师）**：可选
   - **Location（上课地点）**：例如 "Glass Hall 467"
   - **Online（在线课程）**：勾选表示在线课程
   - **Meeting Times（上课时间）**：点击 "+ Add Meeting" 添加上课时间
     - Day（星期）：选择周一到周日
     - Start Time（开始时间）：例如 "09:30"
     - End Time（结束时间）：例如 "10:45"
   - **Office Hours（办公时间）**：可选，点击 "+ Add Office Hour" 添加
3. 点击 **"Save Course"** 保存

#### 编辑课程 (Edit Course)

1. 在 Schedule（课表）视图中找到要编辑的课程
2. 点击 **"Edit"** 按钮
3. 修改信息后点击 **"Save Course"**

#### 删除课程 (Delete Course)

1. 在 Schedule（课表）视图中找到要删除的课程
2. 点击 **"Delete"** 按钮
3. 确认删除（注意：删除课程会同时删除该课程的所有事件）

### 3. 📅 Schedule（学期课表）

Schedule 视图提供两种查看方式：

#### 表格视图 (Table View)

- 显示所有课程的详细信息
- 列包括：课程名称、Section、教室、上课日、时间、教师
- 支持在线/线下标识
- 可直接在表格中编辑和删除课程

#### 日历视图 (Calendar View)

- 按周显示课程安排
- 直观展示每天的上课时间
- 不同课程用不同颜色标识
- 支持左右切换查看不同周的安排

### 4. 🗓️ Calendar（日历视图）

完整的日历视图，显示所有事件。

**功能：**

- **月度视图：** 显示整个月的所有事件
- **事件类型：**
  - 课程（蓝色）
  - 考试（红色）
  - 作业截止日期（蓝色）
  - 个人活动（绿色）
  - 学术日历事件（橙色）
  - 节假日（橙色）
- **导航：** 支持前后月份切换
- **筛选：** 可以筛选不同类型的事件

### 5. 📋 All Events（综合事件视图）

显示所有事件的完整列表。

**事件类型：**

- **CLASS（课程）**：常规课程安排
- **EXAM（考试）**：考试安排
- **QUIZ（测验）**：小测验
- **ASSIGNMENT（作业）**：作业截止日期
- **PROJECT（项目）**：项目截止日期
- **PRESENTATION（演示）**：演示时间
- **LAB（实验）**：实验课
- **INFO（信息）**：一般信息
- **HOLIDAY（节假日）**：节假日
- **DEADLINE（截止日期）**：其他截止日期

**操作：**

- **编辑事件：** 点击事件可以编辑
- **删除事件：** 点击 "Delete" 可以删除
- **筛选：** 可以按类型、课程、日期范围筛选

### 6. 📤 Syllabus Planner（教学大纲导入）

这是系统的核心功能之一，可以智能解析 Syllabus 文本，自动提取课程事件。

#### 使用步骤

1. **准备 Syllabus 文本**
   - 从 Canvas、Blackboard 等 LMS 系统复制教学大纲内容
   - 或从 PDF 文档中复制文本
   - 确保包含日期和时间信息

2. **粘贴并解析**
   - 点击导航栏的 **"Course Schedule Planner"** 按钮
   - 将 Syllabus 文本粘贴到文本框中
   - 点击 **"Parse Text"** 按钮开始解析

3. **审查和确认**
   - 系统会显示解析结果（Candidates）
   - 每个候选事件显示：
     - **Title（标题）**：提取的事件名称
     - **Date & Time（日期和时间）**：提取的日期和时间
     - **Type（类型）**：自动识别的类型（EXAM、ASSIGNMENT 等）
     - **Confidence（置信度）**：解析的可靠程度（0-1）
     - **Needs Review（需要审查）**：标记为需要人工确认的事件
     - **Original Snippet（原始片段）**：提取自的原始文本
   - 审查每个事件，可以编辑日期、时间、标题
   - 勾选要保存的事件
   - 点击 **"Confirm Selected"** 保存

4. **高级功能**
   - **选择课程：** 可以将事件关联到特定课程
   - **批量编辑：** 支持批量修改事件类型
   - **预览：** 可以在保存前预览所有事件

#### 解析能力

系统支持识别以下格式的日期和时间：

**日期格式：**
- "February 15, 2026"
- "Feb 15, 2026"
- "2/15/2026" 或 "02/15/2026"
- "15 Feb 2026"
- 日期范围："March 9-17, 2026"

**时间格式：**
- "11:59 PM" 或 "11:59PM"
- "23:59"（24 小时制）
- "5pm" 或 "5 pm"
- "8:00 AM" 或 "8:00AM"
- "noon"（中午 12:00）
- "midnight"（午夜 00:00）
- "by 11:59 PM"（截止时间）

**特殊关键词：**
- "Due"、"Deadline"、"Submit by" → 识别为截止日期
- "Exam"、"Midterm"、"Final"、"Test" → 识别为考试
- "Quiz" → 识别为测验
- "Spring Break"、"No Class" → 识别为假期/无课日

#### 模板和指南

系统提供 Syllabus 模板（点击 "Guide/Template" 按钮），建议格式：

```
ASSIGNMENT DUE: Chapter 11 (February 15, 11:59 PM)
Quiz 1 (Feb 3, 8:00 AM)
Midterm Exam (March 7, noon)
Project due (April 1, midnight)
Spring Break (March 9–17) – No Class
Final Exam Period (May 4–9)
```

**建议：**
- 每个重要事件包含日期
- 如果有时间，放在同一行用括号标注：`(February 15, 11:59 PM)`
- 避免使用 UTC/Z/时区后缀
- 使用标准日期格式（月/日/年 或 月名 日, 年）

### 7. 📝 Personal Activities（个人活动）

管理个人日程和活动。

#### 添加个人活动

1. **方式一：快速添加（Quick Add）**
   - 在 Dashboard 或 All Events 视图中
   - 使用快速添加文本框
   - 输入简单的文本，例如："Team meeting tomorrow 3pm"
   - 系统会尝试解析日期和时间

2. **方式二：完整表单**
   - 点击 **"+ Add Personal Activity"** 按钮
   - 填写完整信息：
     - Title（标题）
     - Date & Time（日期和时间）
     - All Day（全天事件）
     - Category（分类）
     - Description（描述）

3. **使用模板**
   - 系统提供常用活动模板
   - 例如："Study Group"、"Office Hours"、"Project Meeting"
   - 点击模板可以快速创建类似活动

#### 编辑和删除

- 在 All Events 视图中找到个人活动
- 点击事件可以编辑
- 点击 "Delete" 可以删除

### 8. ⚙️ Settings（设置）

#### Term Settings（学期设置）

**重要性：** 必须正确设置学期信息，系统会根据学期日期自动处理事件。

1. **Term Name（学期名称）**：例如 "Spring 2026"
2. **Start Date（开始日期）**：学期开始日期
3. **End Date（结束日期）**：学期结束日期
4. **Timezone（时区）**：默认 "America/Chicago"（美国中部时区）

**注意：**
- 学期日期用于：
  - 自动筛选学期内的事件
  - Syllabus 解析时推断年份
  - 学术日历事件显示
- 如果不设置学期，某些功能可能无法正常工作

#### Theme（主题）

系统提供两种主题：

- **Marble（大理石）**：优雅的渐变背景，玻璃态效果
- **Default（默认）**：简洁的白色背景

点击主题按钮可以切换。

#### Language（语言）

支持中英文切换：

- **中文**：完整的中文界面
- **English**：完整的英文界面

点击语言按钮可以切换，切换后立即生效。

### 9. 📥 Export Calendar（导出日历）

将课程安排和事件导出为 ICS 格式，可以导入到 Google Calendar、Apple Calendar、Outlook 等日历应用。

#### 使用步骤

1. 点击导航栏的 **"Export Calendar"** 按钮
2. 系统会自动生成 ICS 文件
3. 下载文件（通常命名为 `course_schedule.ics`）
4. 导入到日历应用：
   - **Google Calendar：** 创建新日历 → 导入 → 选择 ICS 文件
   - **Apple Calendar：** 文件 → 导入 → 选择 ICS 文件
   - **Outlook：** 文件 → 打开和导出 → 导入/导出 → 从文件导入

#### 导出内容

- ✅ 所有课程安排（Course Meetings）
- ✅ 所有作业截止日期（Assignment Deadlines）
- ✅ 所有考试时间（Exam Times）
- ✅ 所有个人活动（Personal Activities）
- ✅ 学术日历事件（Academic Calendar Events）
- ✅ 时区信息（America/Chicago）

#### 注意事项

- 导出的时间使用本地时区（America/Chicago）
- 全天事件会正确标记
- 重复事件（如每周课程）会作为单独事件导出

### 10. 🏫 Academic Calendar（学术日历）

系统集成了 MSU（密苏里州立大学）的学术日历，自动显示：

- **学期重要日期：**
  - 学期开始/结束日期
  - 注册日期
  - 退课截止日期
  - 期中考试周
  - 期末考试周
  - 春假/秋假
  - 节假日

- **Final Exam Schedule（期末考试安排）：**
  - 根据课程的上课时间和星期几自动计算期末考试时间
  - 支持特殊课程的期末考试规则（如数学课程）
  - 自动显示在 Dashboard 和 Calendar 视图中

**注意：** 学术日历数据已内置在系统中，无需额外配置。

## 💾 数据管理

### 数据存储

- **存储位置：** 浏览器 localStorage（本地存储）
- **存储内容：**
  - 课程信息（Courses）
  - 事件信息（Events）
  - 个人活动（Personal Activities）
  - 学期设置（Term Settings）
  - 主题偏好（Theme Preference）
  - 语言偏好（Language Preference）

### 数据备份

**重要：** localStorage 数据可能会因为以下原因丢失：

- 清除浏览器缓存
- 使用浏览器的"清除数据"功能
- 使用隐私/无痕模式（关闭后数据会清除）
- 浏览器崩溃或重装

**建议：**

1. **定期导出备份：**
   - 使用 "Export Calendar" 功能定期导出 ICS 文件
   - 保存到云端或本地备份

2. **导出设置：**
   - 截图保存学期设置
   - 手动记录重要课程的详细信息

3. **多浏览器同步：**
   - 在不同浏览器中使用相同的导出文件
   - 或使用浏览器同步功能（如果支持 localStorage 同步）

### 数据导入

目前不支持直接导入数据，但可以通过以下方式恢复：

1. **重新添加课程：** 手动重新添加课程信息
2. **重新解析 Syllabus：** 如果有 Syllabus 文本，可以重新解析
3. **从导出的 ICS 文件：** 可以查看 ICS 文件内容作为参考

## 🔧 故障排除 (Troubleshooting)

### 常见问题

#### 1. 页面显示为空白或一直加载

**可能原因：**
- 网络连接问题（首次加载需要网络）
- 浏览器缓存问题
- JavaScript 被禁用

**解决方法：**
- 检查网络连接
- 清除浏览器缓存后重新加载
- 检查浏览器设置，确保 JavaScript 已启用
- 尝试使用其他浏览器

#### 2. 语言切换不工作

**可能原因：**
- 浏览器不支持 localStorage
- 语言按钮未正确触发

**解决方法：**
- 刷新页面
- 检查浏览器控制台是否有错误
- 尝试手动在浏览器控制台输入：`localStorage.setItem('lang', 'zh')` 或 `localStorage.setItem('lang', 'en')`

#### 3. Syllabus 解析不准确

**可能原因：**
- Syllabus 文本格式不规范
- 日期/时间格式不标准
- 文本包含过多无关信息

**解决方法：**
- 使用系统提供的模板格式
- 清理 Syllabus 文本，移除无关内容
- 确保日期和时间格式标准（见上文格式说明）
- 手动编辑解析结果中的不准确项目

#### 4. 导出的日历时间不正确

**可能原因：**
- 学期时区设置不正确
- 系统时区与学期时区不匹配

**解决方法：**
- 检查 Settings 中的时区设置（默认应该是 America/Chicago）
- 确保导入日历应用时选择正确的时区
- 检查导出的 ICS 文件中的时区信息

#### 5. 数据丢失

**可能原因：**
- 清除了浏览器缓存
- 使用了隐私模式
- 浏览器更新或重装

**解决方法：**
- 定期使用 "Export Calendar" 功能备份
- 避免在隐私模式下使用
- 使用浏览器同步功能（如果支持）

#### 6. 某些功能无法使用

**可能原因：**
- 未设置学期信息
- 浏览器不支持某些 API
- JavaScript 错误

**解决方法：**
- 首先检查 Settings 中的学期设置是否正确
- 查看浏览器控制台是否有错误信息
- 尝试刷新页面
- 使用现代浏览器（Chrome、Firefox、Safari、Edge）

### 浏览器兼容性

**推荐浏览器：**
- ✅ Chrome 90+（最佳兼容性）
- ✅ Firefox 88+
- ✅ Safari 14+
- ✅ Edge 90+

**不推荐：**
- ⚠️ Internet Explorer（已停止支持）
- ⚠️ 旧版浏览器（可能不支持某些功能）

### 性能优化建议

1. **减少事件数量：** 如果事件过多（>1000），可能会影响性能
2. **定期清理：** 删除过期的事件和课程
3. **使用筛选：** 使用筛选功能查看特定事件，而不是显示所有事件

## 🔒 隐私和安全

### 数据隐私

- ✅ **本地存储：** 所有数据仅存储在您的浏览器本地，不会上传到任何服务器
- ✅ **无需登录：** 系统不需要任何账户或登录信息
- ✅ **无追踪：** 系统不包含任何追踪代码或分析工具（除了必要的 CDN 资源）

### 安全建议

- ⚠️ **不要在公共电脑上使用：** 如果使用公共电脑，请在使用后清除浏览器数据
- ⚠️ **保护您的数据：** 定期备份重要数据
- ⚠️ **谨慎分享：** 如果您导出 ICS 文件分享给他人，请确保不包含敏感信息

### 遇到问题？

1. **查看本文档：** 首先查看本文档的故障排除部分
